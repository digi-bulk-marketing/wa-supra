# WA SUPRA

WA SUPRA by WA SUPRA.

## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/wa-supra/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **WA SUPRA** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/wa-supra/releases/latest) and reinstall.
